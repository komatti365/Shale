## 🚀 主な機能
- **Blue Archive / SCHALE OS デザインシステム**: シアン・ネイビー・ヘイローアクセント、ホログラムHUD
- **Web Audio API によるSFX音響演出**: クリック音・端末ビープ音・承認スタンプ押印音（消音トグル付き）
- **キヴォトス時計 & 連邦生徒会公報ティッカー**: リアルタイム時計と事案速報ログ
- **シッテムの箱（SHITTIM-OS）端末**: アロナ＆プラナとの対話、カフェ来訪確認、★3ピンク封筒お仕事占い（`gacha`）など
- **事案支援・任務申請システム**: 各学園からの要請受理と「APPROVED 先生 承認済」の赤インク印鑑捺印ギミック
- **事案調査アーカイブ**: 主要ストーリー・自治区危機の機密調査ファイル閲覧モーダル

## 🛠️ ローカル実行方法
ブラウザで `index.html` を直接開くか、任意のローカルサーバーを起動して閲覧できます。

```bash
# Pythonの場合
python -m http.server 8080

# Node.js (npx) の場合
npx serve .
```
